# LIN-001 - Linux Filesystem Hierarchy

## Objective

Understand the purpose of the most important Linux filesystem directories and learn where the operating system stores configuration files, logs, temporary files, and kernel information.

---

## Directories

### /etc

**Purpose**

Contains system-wide configuration files for Linux and installed applications.

**Common files**

/etc/passwd

Stores user account information.

/etc/group

Stores system group information.

/etc/hosts

Local hostname-to-IP mappings.

/etc/resolv.conf

DNS resolver configuration.

/ssh/sshd_config

SSH server configuration.

/etc/fstab

Filesystem mount configuration.


**Useful commands**

cat /etc/os-release

cat /etc/passwd

cat /etc/group

cat /etc/hosts

ls /etc


### /var

**Purpose**

Stores variable data that changes during normal system operation.

Examples include log files, caches, databases, mail queues and application state.

---

**Common directories**

- `/var/log` – system and application log files
- `/var/cache` – cached data used by applications
- `/var/tmp` – temporary files preserved longer than `/tmp`
- `/var/lib` – application state and persistent data
- `/var/spool` – queued jobs (e.g. mail, printing)
- `/var/run` (or `/run`) – runtime information such as PID files and sockets

---

**Useful commands**

```bash
ls /var

ls /var/log

du -sh /var/*

tail -f /var/log/system.log
```

---

**Interview notes**

- `/var` stands for **variable**.
- Data stored here changes frequently while the system is running.
- Log files are commonly located in `/var/log`.
- Many services store their persistent data under `/var/lib`.

### /proc

**Purpose**

`/proc` is a virtual filesystem that provides real-time information about the Linux kernel, hardware, and running processes. The files are generated dynamically by the kernel and do not exist on disk.

---

**Common files**

- `/proc/cpuinfo` – CPU information
- `/proc/meminfo` – Memory usage information
- `/proc/uptime` – System uptime
- `/proc/version` – Linux kernel version
- `/proc/self` – Symbolic link to the current process
- `/proc/<PID>` – Information about a specific running process

---

**Useful commands**

```bash
cat /proc/cpuinfo

cat /proc/meminfo

cat /proc/uptime

cat /proc/version

ls /proc

echo $$

ls /proc/$$
```

---

**Interview notes**

- `/proc` is a **virtual filesystem**.
- Files are generated by the Linux kernel on demand.
- Most files have a size of **0 bytes** because they are not stored on disk.
- Each numeric directory represents a running process (PID).
- `/proc` is commonly used for system monitoring and troubleshooting.

### Example

```bash
cat /proc/$$/environ | tr '\0' '\n'

Displays environment variables of the current shell by replacing the NULL (`\0`) delimiter with newlines.

This demonstrates that some files in `/proc` use NULL characters instead of newline characters as separators.
```

### /sys

**Purpose**

`/sys` is a virtual filesystem that exposes information about hardware devices, kernel objects, drivers and system configuration. It provides an interface between the Linux kernel and hardware.

---

**Common directories**

- `/sys/block` – block devices
- `/sys/class` – device classes
- `/sys/devices` – hardware devices
- `/sys/module` – loaded kernel modules
- `/sys/kernel` – kernel information

---

**Useful commands**

```bash
ls /sys

ls /sys/block

ls /sys/devices

ls /sys/module
```

---

**Interview notes**

- `/sys` is a virtual filesystem.
- It exposes hardware and kernel information.
- It is commonly used for hardware inspection and configuration.
- Unlike `/proc`, it focuses on devices and kernel objects rather than processes.


### /tmp

**Purpose**

`/tmp` stores temporary files created by the operating system and applications. These files are not intended for long-term storage and may be removed automatically.

---

**Common files**

- Temporary application files
- Installer temporary files
- Temporary archives
- Lock files

---

**Useful commands**

```bash
ls /tmp

touch /tmp/test.txt

rm /tmp/test.txt
```

---

**Interview notes**

- `/tmp` is used for temporary data.
- Files may be deleted automatically after reboot or after a certain period.
- Applications use `/tmp` for short-lived files.

### /home

**Purpose**

`/home` contains personal directories for regular users. Each user has a separate home directory where personal files and user-specific configuration are stored.

---

**Common files**

- `.bashrc`
- `.profile`
- `.ssh/`
- `.gitconfig`
- User documents and downloads

---

**Useful commands**

```bash
cd ~

pwd

ls -la
```

---

**Interview notes**

- Every regular user has a home directory.
- User-specific configuration files are usually stored here.
- Personal files should be stored inside the user's home directory.

## Practical Commands

```bash
ls -la /etc | head
ls -la /var
ls -la /proc | head
ls -la /sys
ls -la /tmp
ls -la /home

cat /proc/cpuinfo | head
cat /proc/meminfo | head
cat /etc/os-release
```
