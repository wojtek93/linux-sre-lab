# LIN-10 – Memory

## Objective

Learn how Linux manages memory and how to inspect RAM usage, swap usage and process memory information using standard Linux tools.

---

## Commands Used

### Display memory usage

```bash
free -h
```

Shows total, used, free, cached and available RAM as well as swap usage.

---

### Monitor memory statistics

```bash
vmstat 1
```

Displays real-time memory, swap, CPU and I/O statistics.

---

### Show processes using the most memory

```bash
ps aux --sort=-%mem | head
```

Lists processes sorted by memory consumption.

---

### Display system memory information

```bash
cat /proc/meminfo
```

Shows detailed memory statistics generated by the Linux kernel.

---

### Display information about a running process

```bash
cat /proc/<PID>/status
```

Displays process state, PID, PPID, user IDs, group IDs and memory usage.

Example:

```bash
cat /proc/5330/status
```

---

## Important Memory Fields

### MemTotal

Total physical RAM installed in the system.

---

### MemFree

Completely unused RAM.

---

### MemAvailable

Memory available for new applications without swapping.

This includes free memory and reclaimable cache.

---

### Buffers

Memory used by the kernel for filesystem metadata and block I/O buffers.

---

### Cached

RAM used to cache file contents for faster access.

---

### SwapTotal

Total configured swap space.

---

### SwapFree

Currently unused swap space.

---

### VmRSS

Actual physical RAM currently used by a process.

---

### VmSize

Current virtual memory allocated to a process.

---

## Notes

- `/proc` is a virtual filesystem.
- Files inside `/proc` are generated dynamically by the Linux kernel.
- `/proc/meminfo` contains system-wide memory information.
- `/proc/<PID>/status` contains information about a single running process.

---

## Interview Notes

Be able to explain:

- Difference between RAM and Swap.
- Difference between **MemFree** and **MemAvailable**.
- Why Linux uses memory for cache.
- How to identify memory-consuming processes.
- What information can be found in `/proc/<PID>/status`.

Example interview answer:

> Linux provides several tools to monitor memory usage such as `free`, `vmstat` and `ps`. Detailed system memory information is available in `/proc/meminfo`, while `/proc/<PID>/status` provides information about an individual process including its state, identifiers and memory consumption.
