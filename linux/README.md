# Linux SRE Lab

A hands-on Linux laboratory designed to build practical Linux administration, Bash scripting, DevOps, and Site Reliability Engineering (SRE) skills.

This repository contains a collection of small labs covering core Linux concepts commonly used in production environments and technical interviews.

---

## Learning Goals

The purpose of this repository is to gain practical experience with:

- Linux command line
- Bash scripting
- Process management
- Signals
- File systems
- Permissions
- System administration
- Log analysis
- Performance monitoring
- Storage management
- Cron jobs
- Troubleshooting

Every lab focuses on one specific topic and includes documentation together with practical experiments.

This repository documents my Linux learning journey through practical exercises.

The focus is on understanding Linux internals by building small projects, writing Bash scripts, and documenting experiments rather than simply learning commands by memory.

The knowledge gained here is intended for DevOps, Site Reliability Engineering (SRE), and Linux Systems Engineer roles.
