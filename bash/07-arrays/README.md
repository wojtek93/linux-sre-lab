# Lab 07 - Arrays

## Objective

Learn how to work with Bash arrays by parsing the `PATH` environment variable.

## Skills Practiced

- Arrays
- IFS
- read -a
- for loop
- Directory validation
- Arithmetic operations

## Files

```
path_audit.sh
```

## Run

```bash
chmod +x path_audit.sh
./path_audit.sh
```

## What I Learned

- Creating arrays
- Parsing `PATH`
- Using `IFS`
- Iterating through arrays
- Checking directories with `[[ -d ]]`
- Counting results
