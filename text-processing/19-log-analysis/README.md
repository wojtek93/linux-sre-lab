## Completed Tasks

### 1. Display all HTTP errors (4xx and 5xx)

```bash
sed -n '/[45][0-9][0-9]$/p' input/access.log
```

---

### 2. Count requests handled by each server

```bash
cut -d' ' -f2 input/access.log \
| sort \
| uniq -c \
| awk '{print $2,$1}'
```

---

### 3. Display unique endpoints

```bash
awk '{print $4}' input/access.log \
| sort \
| uniq
```

---

### 4. Count HTTP status codes

```bash
awk '{print $5}' input/access.log \
| sort \
| uniq -c \
| awk '{print $2,$1}'
```

---

### 5. Display all requests to /login

```bash
awk '$4=="/login"' input/access.log
```

---

### 6. Display WARNING and ERROR messages

```bash
sed -n '/WARNING/p;/ERROR/p' input/system.log
```

---

### 7. Count log levels

```bash
awk '{print $1}' input/system.log \
| sort \
| uniq -c \
| awk '{print $2,$1}'
```

---

### 8. Display Running Kubernetes Pods

```bash
jq -r '.[] | select(.status=="Running") | .name' input/pods.json
```

---

### 9. Display HTTP errors generated by web02

```bash
grep -E '[45][0-9]{2}$' input/access.log \
| grep 'web02'
```

---

### 10. Count HTTP 200 responses

```bash
awk '$5==200 {count++} END{print count}' input/access.log
```

---

### 11. Count Running Pods

```bash
jq '[.[] | select(.status=="Running")] | length' input/pods.json
```

## Common Analysis Pipelines

### Count unique values

```bash
awk '{print $N}' file \
| sort \
| uniq -c
```

---

### Filter HTTP errors

```bash
grep -E '[45][0-9]{2}$'
```

---

### Filter JSON objects

```bash
jq -r '.[] | select(...) | .field'
```

---

### Count filtered JSON objects

```bash
jq '[.[] | select(...)] | length'
```

## Real-World Examples

### Count requests per IP

```bash
awk '{print $1}' access.log \
| sort \
| uniq -c
```

---

### Find failed requests

```bash
grep -E ' [45][0-9]{2}$' access.log
```

---

### Running Kubernetes Pods

```bash
kubectl get pods -o json \
| jq -r '.items[] | select(.status.phase=="Running") | .metadata.name'
```

---

### Count Running Pods

```bash
kubectl get pods -o json \
| jq '[.items[] | select(.status.phase=="Running")] | length'
```
